Connect to an Apple TV timer

  1. Open WDJJ Timer on the Apple TV.
  2. Connect the Apple TV and your iPhone or iPad to the same local network.
  3. Open WDJJ Timer Controller and allow Local Network access if prompted.
  4. Select the nearby timer shown on the connection screen.
The connection stays on your local network. No account or internet service is required.

Use the timer locally

Select Use Locally on the connection screen to run the complete timer on your iPhone or iPad. Local mode works without an Apple TV, internet connection, or local network.

Select Exit Local Mode to return to nearby timer discovery.

Configure a match

Set the round length, number of rounds, and break duration with the minus and plus controls. Swipe left to choose a preset, then swipe right to return to the controller.

Select Start when the match is ready.

Control the timer

Use Pause Round and Resume Round to stop and continue the clock. Restart Round returns to the three-second countdown for the current round. End stops the match and returns to setup.

Timer sounds

When connected to Apple TV, enable Controller Sounds to play synchronized cues on the iPhone or iPad. In local mode, countdown and round-ending sounds always play on the device.
