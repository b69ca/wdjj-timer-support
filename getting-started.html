Setup guide

Run your first match.

WDJJ Timer is designed to be readable across the room and simple to operate with the Apple TV remote.

Configure a match

  1. Open WDJJ Timer on your Apple TV.
  2. Set Round length using the minus and plus controls.
  3. Choose the number of Rounds. You can configure up to 50.
  4. Set the Break between rounds.
  5. Select Start when everyone is ready.

Run the timer

Each round begins with a three-second countdown. Short beeps mark 3, 2, and 1, followed by a longer beep when the round begins.

During a round, use Pause Round to stop the clock temporarily. Select Resume Round to continue from the same time.

Use Restart Round to return to the countdown for the current round.

Between rounds

When a round ends, WDJJ Timer plays the end signal and automatically starts the configured break. The display counts down the seconds until the next round begins.

The app stays on the same dark background throughout the match to avoid distracting brightness changes in the room.

Finish or reset

Select End to stop the active match and return to setup. At the end of the final round, select Reset to prepare another match.

Moving the app into the background stops and resets any active timer. This prevents a hidden timer from continuing while another Apple TV app is in use.
