Privacy Policy

WDJJ Timer does not collect personal data.

Summary

WDJJ Timer is a match timer for Apple TV. The app does not require an account and does not include advertising, analytics, or tracking.

WDJJ Timer does not collect, store, sell, rent, or share personal information.

Data collection

WDJJ Timer does not collect personal information, usage information, diagnostic information, precise location, contact details, identifiers, payment information, health information, or user-generated content.

The app does not send information to Jon Wallace or to any cloud service operated on his behalf.

Local network communication

WDJJ Timer may use the Apple TV’s local network to advertise its availability and receive timer commands from compatible devices on the same network. This communication stays within the local network and is used only to operate the timer.

The app does not use local-network communication to identify users, build profiles, or transmit data to an external server.

Children’s privacy

Because WDJJ Timer does not collect personal information from any user, it does not knowingly collect personal information from children.

This support website

This website is hosted by GitHub Pages. Visiting it is separate from using the WDJJ Timer app. GitHub may process limited technical information, such as IP addresses and request logs, according to the GitHub General Privacy Statement.

If you email support, the information you choose to include will be used only to respond to your request.

Changes to this policy

This policy may be updated if the app’s features or legal requirements change. The effective date at the top of this page will identify the latest version.
